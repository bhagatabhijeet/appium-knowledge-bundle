Beyond the core Appium server, the project maintains a wide ecosystem of officially- and community-supported software, grouped into four categories, per the [Appium Ecosystem](https://appium.io/docs/en/2.0/ecosystem/) documentation:

- **Drivers**: link Appium to a target device or platform (Android, iOS, Windows, a browser, and more). See [How Appium drivers work](/driver-ecosystem/how-drivers-work.md) and the [Appium driver catalog](/driver-ecosystem/drivers.md).
- **Clients**: link Appium to your automation code, one library per programming language. Covered in [Supported languages](/introduction/supported-languages.md).
- **Plugins**: modify or extend Appium's functionality (for example, adding custom commands or altering how existing ones behave). Not yet covered in this bundle.
- **Tools**: interact with Appium in other ways, such as the [Appium Inspector](https://github.com/appium/appium-inspector) for exploring an app's element tree. Not yet covered in this bundle.
